# BhashaSetu UI Design Backup

This directory contains a complete snapshot of the previous horizontal-navigation UI design before transitioning to the warm editorial sidebar + separated `Home`, `Lessons`, and `Settings & preferences` layout.

## Backed-Up Files
- `App.backup.tsx` — Previous top-navigation App shell and combined Home + Curriculum Syllabus dashboard (`src/App.tsx`).
- `ProgressSettingsView.backup.tsx` — Previous Progress, Achievements, and Settings view (`src/components/ProgressSettingsView.tsx`).
- `DictionaryView.backup.tsx` — Previous 10,400+ Lexicon & SRS Dictionary view (`src/components/DictionaryView.tsx`).
- `PracticeArenaView.backup.tsx` — Previous 16-Tool Practice Arena view (`src/components/PracticeArenaView.tsx`).
- `LecturePlayer.backup.tsx` — Previous 5-Step Interactive Lecture Player (`src/components/LecturePlayer.tsx`).

To inspect or restore any part of the previous layout, view the `.backup.tsx` files in this folder.
